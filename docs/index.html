Price Tracker Agent

AI-powered price tracking via messaging channels — built on an autonomous agent architecture.

💬 What It Does

Users message a bot on Telegram (or WhatsApp) with a product name or URL. An autonomous AI agent looks up current prices across retailers, normalizes the data, and stores it for tracking over time.

🧠 How It Thinks

Instead of keyword matching, an LLM-powered agent (OpenClaw) decides how to fulfill each request. Skills like price-check define the agent's capabilities via markdown instructions.

📊 What It Tracks

Products are normalized into a 4-layer hierarchy: Product → Variant → Listing → PriceSnapshot. JSONB attributes handle category-specific fields (storage for phones, fabric for sofas) without schema migrations.

🔒 Security Model

The AI agent runs exclusively inside Docker — never locally. It has no exposed ports to the host. Our web app communicates with it over the internal Docker network only.

Architecture & Design Decisions

High-Level Flow

User (Telegram) → FastAPI webhook → OpenClaw Agent (Docker) → Structured JSON
                                                                    ↓
                                    Telegram reply ← agent.py ← store.persist_agent_response()
                                                                    ↓
                                                    Product → Variant → Listing → PriceSnapshot (Postgres)

Key Design Decisions

DecisionChoiceWhy
Channel layerStrategy Pattern (Channel ABC)Add Telegram/WhatsApp/Email without modifying existing code
Agent frameworkOpenClaw (containerized)LLM-powered skill routing replaces brittle keyword matching
Agent isolationDocker-only, no host portsSecurity — agent cannot escape container; app talks via internal network
LLM providerGemini (swappable via env)Factory pattern through OPENCLAW_MODEL_PROVIDER env var
Variant attributesPostgreSQL JSONBCategory-specific fields without schema migrations (vs EAV or separate tables)
Session strategyPer-user (chat_id)Multi-turn conversations — "track it" refers to the last product discussed
Store patternstore/ package (not raw queries)ACID-compliant, race-condition safe with IntegrityError fallback
ORMSQLAlchemy + create_allFast iteration; Alembic planned for production migrations
TelemetryPrometheus + Grafana + LokiFull-stack observability: metrics, dashboards, and centralized logs

Data Model (4-Layer Hierarchy)

Product: "iPhone 16 Pro" (brand=Apple, category=smartphones)
├── Variant: "128GB, Space Black" (attributes={storage:128GB, color:Space Black})
│   ├── Listing: Amazon  → $999  ⭐4.7 (2,341 reviews)
│   ├── Listing: BestBuy → $979  ⭐4.6 (891 reviews)
│   └── Listing: Apple   → $999  ⭐4.8 (5,612 reviews)
│       └── PriceSnapshot: $999 @ May 3, $1029 @ Apr 28, ...
│
└── Variant: "256GB, White Titanium" (attributes={storage:256GB, color:White Titanium})
    └── Listing: Apple   → $1,099 ...

Running & Operations

Prerequisites

Docker, Docker Compose, and a .env file (copy from .env.example). You need a TELEGRAM_BOT_TOKEN from @BotFather and a GEMINI_API_KEY.

Start Everything

# First time (pulls OpenClaw image ~700MB)
docker compose up -d

# Rebuild after code changes
docker compose up -d --build web

# View logs
docker compose logs web --tail 50 -f
docker compose logs openclaw --tail 50 -f
